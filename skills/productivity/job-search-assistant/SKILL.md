# Job Search Assistant

Автоматизированный пайплайн для поиска вакансий на hh.ru и генерации персонализированных сопроводительных писем.

## hh.ru API — OAuth Setup

### Регистрация приложения
1. Перейти на https://dev.hh.ru/
2. Авторизоваться через личный аккаунт hh.ru
3. «Личный кабинет» → «Добавить приложение»
4. Заполнить:
   - **Название**: `JobSearch Assistant` (или любое)
   - **Описание**: краткое назначение
   - **Callback URL**: `http://localhost:8080/callback` (агент подменит)
   - **Scopes**: `Поиск вакансий` (vacancies) — минимум
5. Скопировать `Client ID` и `Client Secret`

### Авторизация (OAuth flow)
- Агент генерирует URL авторизации, пользователь переходит и подтверждает доступ.
- Агент обменивает code на `access_token`.
- Токен хранится в `~/.hermes/cache/hh_token.json`.

### Поисковые параметры (по умолчанию для этого пользователя)
- `text`: Media Buyer (также: SMM-менеджер, маркетолог, интернет-маркетолог)
- `schedule`: remote
- `salary_from`: 1000
- `currency`: USD
- `per_page`: 20

> **Важно**: API требует `User-Agent` заголовок. Без него — 403 Forbidden.

## Резюме — Правила обновления (КРИТИЧНО)

При редактировании резюме пользователя **строго соблюдать**:

| ❌ НЕЛЬЗЯ | ✅ НУЖНО |
|-----------|---------|
| Объяснять причины ухода с позиции | Фиксировать только факты и достижения |
| Упоминать очевидные технические детали: Pixel, Events API, антидетект, прокси | Упоминать: организацию структуры, подключение агентств/фарм-отдела, обучение баеров, вывод процессов в стабильный режим |
| Писать «не пошло / закрыли / сократили» без подтверждения | Краткие проекты оформлять как «запуск направления / проектная занятость» |

- **Тон**: фактический, нейтральный, профессиональный.
- **Формулировка ухода**: не писать. Просто зафиксировать опыт.

## Генерация сопроводительных писем

Для каждой вакансии:
1. Распарсить описание вакансии — выделить ключевые требования.
2. Сопоставить с резюме пользователя (опыт, ниши, достижения).
3. Сгенерировать 3–4 предложения, highlighting релевантный опыт.
4. Упомянуть конкретные цифры, если есть (бюджеты, размер команды, ROI).
5. Тон: уверенный, но не высокомерный.
6. Формат доставки в Telegram:
   ```
   📋 Вакансия: [Должность]
   🏢 Компания: [Название]
   💰 Зарплата: [Диапазон]
   🔗 Ссылка: [URL]

   Готовое письмо:
   [Текст]

   Отправить? (Да / Нет / Переписать)
   ```

## Автоматизация — Cron Job

- **Частота**: раз в сутки
- **Доставка**: Telegram батчем (3–5 лучших совпадений)
- **История**: `~/.hermes/cache/job_search/` — хранить ID уже показанных вакансий, чтобы не дублировать.
- **Фильтр дубликатов**: проверять `vacancy.id` перед генерацией письма.

## Fallback: браузерный парсинг

Если OAuth недоступен:
1. Открыть https://hh.ru/search/vacancy?text=Media+Buyer&schedule=remote&salary_from=1000&currency=USD
2. Собрать ссылки и заголовки через browser snapshot.
3. **Риск**: CAPTCHA и rate limiting. Использовать только если OAuth заблокирован.

## Pitfalls
- hh.ru API возвращает `salary_from`/`salary_to` не во всех вакансиях — проверять наличие поля.
- `currency` в API — код (RUR, USD, EUR), не символ.
- Некоторые вакансии скрывают зарплату — фильтровать по `salary_from` на уровне API, но проверять что поле не null.
