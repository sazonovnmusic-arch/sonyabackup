## Writing Style — Detailed Breakdown

### 1. Opening Hook (MUST HAVE)

Always starts with a provocative question or bold statement. Patterns:

- **"А ты заметил эти [скрытые детали / киноляпы / пасхалки / странности] в [мультфильм]?"**
- **"А ты знал, что [шокирующий факт]?"**
- **"Многие не заметили [этих отсылок / этих деталей] в [мультфильм]!"**
- **"Спорим, ты не [видел / заметил] [деталь]?"**
- **"Ты знал, что [персонаж] [сделал что-то]?"**
- **"Почему [персонаж] [делает что-то странное]?"**
- **"Какая [суперспособность / эмоция] [самая сильная]?"**
- **"Топ 5 секретов, которые [авторы спрятали / ты не заметил] в [мультфильм]!"**
- **"Это самое [жуткое / странное], что [нас ждёт / мы знаем о]..."**
- **"Три [безумные вещи / скрытые отсылки], которые ты [не знал / пропустил]!"**

### 2. Body Structure

**Pattern A — Single topic (3 details):**
1. Hook → Detail 1 (with explanation)
2. "Но [самое интересное / дальше ещё интереснее / самое странное]..."
3. **CTA block** (mid-text, see below)
4. Detail 2 or final reveal
5. Closing question

**Pattern B — Top 5 countdown:**
1. Hook
2. 5 место → 4 место → 3 место → 2 место
3. **CTA block** before 1 место
4. 1 место (most shocking/interesting)
5. Closing question

**Pattern C — Comparison/theory:**
1. Hook (asking if you noticed similarity)
2. Point-by-point comparison or theory buildup
3. **CTA block** mid-text
4. Final revelation (the most shocking point)
5. Closing question

**Pattern D — "3 things" list:**
1. Hook
2. Thing 1 → Thing 2
3. "И [самое странное / напоследок]..."
4. **CTA block**
5. Thing 3
6. Closing question

**Pattern E — Compilation (multiple movies in one Short):**
This is a popular format where each point covers a DIFFERENT movie/franchise. The hook is generic ("Ты замечал эти странности в мультфильмах Pixar?"), then each detail is from a different film. The unifying thread is the TYPE of detail (easter eggs, hidden details, errors, etc.), not the franchise.
1. Hook (generic — covers the theme, not one movie)
2. Detail 1 (Movie A) → Detail 2 (Movie B)
3. "Но [самое интересное / самая странная деталь] дальше..."
4. **CTA block**
5. Detail 3 (Movie C) — the best/most shocking one
6. Closing question

**Pattern E — Multi-movie compilation** (see Multi-Movie Compilation Format section below)

### 3. CTA Block (ALWAYS present, ALWAYS mid-text)

This is critical — the call-to-action is NEVER at the end. It's always placed between the penultimate and final point, creating a cliffhanger effect. The CTA always ties into the content thematically.

**Exact patterns:**

- "Но перед этим [представь / поставь лайк / напиши], что ты [сценарий связанный с контентом]. Если [вариант А] - [действие 1] и поставь лайк, а если [вариант Б] - [действие 2] и подпишись."
- "Но для начала поставь лайк и подпишись на канал!"
- "Но перед этим поставь лайк, подпишись и напиши в комментариях [вопрос по теме]!"
- "А перед этим [напиши / поставь / подпишись]..."

**The CTA always asks the viewer to:**
- Like (поставь лайк)
- Subscribe (подпишись / подпишись на канал)
- Comment with a specific emoji/word related to the content (напиши [слово] в комментариях)
- Sometimes: "А если [оба варианта] - сделай все сразу!"

**Examples from actual texts:**

## Transcript Fetching

### Method: youtube-transcript-api (Python)

```python
from youtube_transcript_api import YouTubeTranscriptApi

# IMPORTANT: The API changed. The OLD class-method style does NOT work:
#   YouTubeTranscriptApi.get_transcript(video_id)  ← BROKEN, do not use
#   YouTubeTranscriptApi.list_transcripts(video_id)  ← BROKEN, do not use
#
# The NEW API requires instantiating the class first:
ytt_api = YouTubeTranscriptApi()
transcript = ytt_api.fetch(video_id, languages=['en', 'es', 'fr', 'de', 'pt'])
text = " ".join([snippet.text for snippet in transcript])
```

### Pitfalls
- Many Shorts do NOT have transcripts (subtitles disabled or never generated). Be prepared to try 5-10 video IDs to get 2-3 successful transcripts.
- Video IDs from search results are sometimes invalid or the video is unavailable — always wrap in try/except.
- The `languages` parameter is a fallback chain — it tries each language in order. Pass multiple languages to increase hit rate.
- If transcript fetching fails for a video, move on to the next candidate — don't waste time retrying the same ID.

## Channel Analysis

When the user shares a **channel URL** (not a single video) or asks to audit/review a YouTube channel, use the browser tools to extract channel-level metadata and video listings. This is distinct from transcript extraction — it's about understanding the channel's theme, performance, and content strategy.

### Steps

1. **Navigate** to the channel URL. YouTube redirects `/channel/UC...` to `/@handle`. Use the handle URL directly if known: `https://www.youtube.com/@handle/shorts` or `/videos`.
2. **Read channel metadata** from the page snapshot: channel name, @handle, subscriber count, total video count, description, links (e.g. Telegram, website).
3. **Extract all video titles + views** via `browser_console` with JavaScript injection. The key pattern:

```javascript
(() => {
  const shorts = [];
  document.querySelectorAll('ytd-rich-item-renderer').forEach(item => {
    const titleEl = item.querySelector('a#video-title-link, a[title]');
    const title = titleEl ? (titleEl.getAttribute('title') || titleEl.textContent?.trim()) : '';
    const href = titleEl?.href || '';
    const allSpans = item.querySelectorAll('span');
    const viewsText = Array.from(allSpans).map(s => s.textContent?.trim())
      .filter(t => t && t.match(/\d+\s*(K|M)\s*views/));
    shorts.push({title, url: href, views: viewsText[0] || ''});
  });
  return JSON.stringify(shorts);
})()
```

4. **Scroll + re-extract** to load more videos (YouTube lazy-loads). Scroll down, then re-run the same JS. Deduplicate by URL. Repeat until no new items appear.
5. **Check the "Popular" tab** — click it and re-extract to rank videos by view count for a quick top-performers list.
6. **Check community posts** — the Posts/Community tab shows polls, which reveal audience engagement (vote counts, comment counts).
7. **Analyze**: group videos by theme/franchise, identify the best-performing content types, note posting cadence, and flag whether the channel is Shorts-only, long-form, or mixed.

### Pitfalls

- **YouTube's accessibility snapshot does not show video titles reliably** — the snapshot often returns empty link text for video grid items. Always fall back to `browser_console` JS extraction rather than relying on the snapshot for video listings.
- **View counts may not appear in the initial snapshot** — they're in overlay spans that the accessibility tree doesn't surface. The JS regex approach above is the reliable extraction method.
- **Scrolling doesn't always load more** — if `ytd-rich-item-renderer` count stops growing after a scroll, the page is fully loaded. Don't loop forever.
- **Variable name collisions in browser_console** — if you run multiple JS evaluations in the same page session, `const items` at top level will collide on re-run. Wrap every extraction in an IIFE `(() => { ... })()` to get a fresh scope each time.
