## Key Observations

1. **Psychology/aura/respect is the #1 trending topic** — appeared across Hindi AND English channels. "How to build respect in class", "dark psychology tips", "aura" content resonates massively with teens.

2. **Hindi channels grow fastest** — Shan 7 got 77K subs in 10 days. Hindi YouTube audience is massive and underserved.

3. **DIY/garden content is language-agnostic** — Create & Grow DIY got 84M views in 2 months with minimal narration. Visual content works across language barriers.

4. **"What-If" format is evergreen** — "Can you drain the ocean?", "What if you had 800 IQ?" — hypothetical scenarios get high engagement.

5. **Quizzes have lower views but high retention** — Quiz Aram only 1.2M total but consistent per-video performance.

6. **Cricket Xtreme anomaly** — 1924x Views/Subs ratio means almost nobody subscribes but videos get recommended heavily. Niche topic with viral reach.

## Technique Notes

- The English-only filter (Latin char ratio > 0.7 on title) successfully separated English channels from Hindi/Arabic ones
- `videoDuration=short` + `order=viewCount` + `publishedAfter` is the correct filter combo
- channels.list batching (50 at a time) is efficient — 65 channels checked in 2 API calls
- Total runtime: ~63 seconds for 12 multi-language queries, ~45 seconds for 20 English queries
- No 429 errors from YouTube Data API (only transcript API has that issue)
